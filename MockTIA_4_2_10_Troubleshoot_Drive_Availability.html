4.2.10 // Troubleshoot Drive Availability

SATA · NVMe · BIOS/UEFI · Disk Management · Device Manager · Command Prompt

Work Order

A Windows workstation cannot access its secondary storage drive. Diagnose the cause without deleting existing files.

Select a fault scenario

Lab tasks

Learning objectives

Distinguish physical detection from Windows volume availability. Understand SATA data/power, NVMe seating, disabled controllers, offline disks, missing letters, and unallocated storage. Avoid destructive actions on drives with user data.

Technician workbench

Why this matters: A drive can be missing from File Explorer while still working electrically. Check whether firmware detects it, whether Windows detects the disk, and whether a usable volume has a drive letter before deciding what to repair.
