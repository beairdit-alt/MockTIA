    Actual configuration procedure

    Field Setup Guide — real Proxmox / Debian / SNMP work

    Use the individual copy boxes in order. Read the explanation first, verify the correct account and system, and check the result before moving on. GUI-only actions are labeled so students do not paste them into a shell.

    Security: public is a deliberately simple training community string, not a secure production credential. Restrict UDP 161 to 10.10.20.29. Prefer SNMPv3 with authentication and privacy on managed networks. LibreNMS on HTTP is restricted to the lab until HTTPS is configured.

    Evidence checklist

    • CT 100 configuration, address 10.10.20.29/24 and gateway 10.10.20.1
    • Successful validate.php output, no FAIL lines
    • SNMP sysDescr/sysName responses from a Proxmox host, OPNsense and an iDRAC
    • LibreNMS Devices page after scan:network
    • Performance graph and written diagnosis of one troubleshooting fault
