Technician Service Ticket

A company laptop uses the enp2s0 Ethernet adapter but has incorrect network settings. Restore stable static IPv4 connectivity to the corporate network.

Required target:
IP: 192.168.0.254/24
Broadcast: 192.168.0.255
Gateway: 192.168.0.5
DNS: 163.128.78.93 and 163.128.80.93

Guided work order

    Instructor note

    This simulated legacy Linux workstation uses an ifcfg file. Modern Ubuntu systems often use Netplan; open the Modern Linux tab to compare.

    Start in the terminal with ip addr show. Click a suggested command or type it yourself.

    Connection Verification

    Terminal quick commands

    How to use this lab

    Run the commands in order, then edit and save the adapter file. Validate and apply the configuration before testing connectivity. Incorrect values are not awarded credit.

    Changing an IP on a real remote Linux computer can interrupt SSH. In production, prepare recovery access before applying changes.
