Reference · IP address anatomy

192.168.0.254 /24

/24 = 255.255.255.0
Network: 192.168.0.0
Hosts: .1 through .254
Broadcast: .255

10.0.255.254 /16

/16 = 255.255.0.0
Network: 10.0.0.0
Hosts: 10.0.0.1 through 10.0.255.254
Broadcast: 10.0.255.255

Protocol Layers

OSI L3: Network

IPv4 address and subnet mask determine logical addressing and local vs routed destinations.

OSI L7: Application

DNS maps hostnames to addresses. The lab tests reachability of a DNS server by IP with ICMP at Layer 3.

OSI L2: Data Link

Ethernet frames deliver traffic to the next hop using MAC addresses.
