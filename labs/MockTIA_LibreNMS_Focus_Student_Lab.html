    Optional field extension · Proxmox Backup Server

    Add VPBS at 10.10.20.3 to LibreNMS

    Students already know how to add Proxmox hosts. Apply the same SNMP principles to a dedicated Proxmox Backup Server without accidentally configuring the wrong shell. This add-on does not change the main 100-point assessment.

    What is PBS?

    Proxmox Backup Server manages backup archives and restore workflows. It is different from Proxmox VE, which manages VMs and containers. SNMP checks the PBS operating system and hardware; it does not confirm backup or restore success.

    What are we building?

    LibreNMS at 10.10.20.29 → UDP 161 → SNMP agent on VPBS 10.10.20.3. Only the monitor may read SNMP; no one needs to open UDP 161 to the internet.
