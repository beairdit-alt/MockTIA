Command reference

ls -l shows owner, group and permissions; chown user path changes owner; chgrp group path changes group; chmod 770 path changes permissions.

Safety: use sudo for privileged ownership changes. Avoid chmod 777; unrestricted access is not appropriate for corporate project data.

Permission quick guide

r = 4 read; w = 2 write; x = 1 execute/traverse.

750 means owner rwx, group r-x, others no access.

770 means owner and group rwx, others no access.

640 means owner rw-, group r--, others no access.
