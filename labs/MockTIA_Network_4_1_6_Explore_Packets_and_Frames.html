🔀 Switching vs Routing · which header changes?

Before router
MAC: WS → gateway
IP: client → server
TCP: 51514 → 80
➜
After router (without NAT)
MAC: router → next hop
IP: client → server
TCP: 51514 → 80
At a router, the Layer 2 Ethernet header is rebuilt for the outgoing link. The IPv4 TTL also decreases. The source/destination IP addresses and TCP ports normally remain end-to-end when NAT and other translation are absent.

Encapsulation · build a web request

The application produces data; the transport layer adds TCP, network layer adds IPv4, and Ethernet wraps the packet in a frame. The receiver removes headers in reverse order.

Protocol Quick Reference

Ethernet: Layer 2 frame, MAC addresses
IPv4: Layer 3 packet, IP addresses, TTL
TCP: Layer 4 segment, ports and flags
HTTP: application request carried in TCP
FCS: Ethernet error-detection field; often omitted from captures

Guided Analysis

Select a packet and expand Ethernet II, Internet Protocol Version 4, or Transmission Control Protocol to reveal the fields.

Learning Targets

Differentiate frame/packet/segment, use a display filter, identify header lengths and destination port, interpret SYN/ACK/PSH, and trace Layer 2 versus Layer 3 forwarding.
