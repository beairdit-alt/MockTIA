MISSION 03 • TROUBLE TICKETS

Find the broken layer

Read the symptoms and choose the most likely root cause. Each ticket is a realistic first-pass diagnosis, not a guarantee about every possible fault.

TOOLS OF THE TRADE

pfSense + packet capture clues

Diagnostics → DNS Lookup Diagnostics → Ping Diagnostics → Routes Firewall → Rules Firewall → NAT → Outbound Diagnostics → States Diagnostics → Packet Capture

Wireshark display filters

dns arp icmp tcp.port == 443 tcp.flags.syn == 1 ip.addr == 10.10.20.55

When diagnosing a handshake, a SYN with no SYN-ACK can indicate filtering, routing, destination availability, or a return-path issue. Use captures at multiple points to narrow it down.
