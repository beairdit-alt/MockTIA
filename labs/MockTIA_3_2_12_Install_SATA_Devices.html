3.2.12 · Install SATA Devices

Lab Tasks

Technician Notes

SATA data connects the drive to a motherboard SATA port. SATA power comes separately from the power supply. Both are needed.

Always power down and unplug before adding internal hardware.

Select a component in the inventory, then click a physical target on the PC image. The target controls below provide keyboard-accessible alternatives.

Installed Hardware and Connections

BIOS / UEFI · SATA Information

A drive appears in BIOS only after correct mounting, SATA data, and power connections. Detection does not mean that Windows has a formatted volume.

Windows Disk Management

The OS disk is already present. Newly detected drives need initialization and a volume before files can be stored.

Knowledge Check

Work Order

Install a 500 GB 2.5-inch SATA SSD and a 1 TB 3.5-inch SATA HDD in the workstation. Connect each device's SATA data and SATA power, verify detection, then initialize and format both drives as NTFS.

Tools

Power controls, drive bays, SATA data leads, PSU SATA power leads, Windows Disk Management, simulated BIOS screen.
