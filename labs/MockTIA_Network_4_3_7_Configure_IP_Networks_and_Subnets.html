Interactive /27 Subnet Explorer

A /27 uses 27 network bits and 5 host bits: 2⁵ = 32 total addresses, 30 usable hosts per subnet.

Identify each workstation's /27 network

Select the correct network ID below, then click Verify. The simulator checks the host address, not just whether a choice was made.

Gateway Configuration & Connectivity

Enter the valid gateway and subnet mask for each /27 workstation. Save each configuration, then connect the switches and test communication.

Link and test

A switch extends the Layer 2 broadcast domain, but it does not route between IP subnets. A router (or Layer 3 switch with routing enabled) is required for cross-subnet communication. The simulator provides a router when each workstation has its correct gateway.

Block size = 32 addresses
Usable = 30 hosts

Critical rule

Two PCs using the same /24 prefix are not automatically in the same /27. Compare their network IDs.
