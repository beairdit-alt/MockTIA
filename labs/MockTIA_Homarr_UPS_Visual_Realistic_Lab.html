📚 Technician reference
NUT driver
Reads raw status from USB-connected UPS devices. usbhid-ups is commonly used with supported HID UPS hardware.
upsd
NUT network service on the Wysebox. Remote clients access named UPS devices over TCP port 3493.
upsmon
Runs on each Proxmox host, watches its assigned UPS, and can request safe shutdown.
PeaNUT
Web application/API on CT 105. Talks to the Wysebox NUT server and presents readable UPS status.
Homarr
Dashboard on CT 100. The UPS widget reads the PeaNUT integration; it does not control host shutdown.
Data vs power
Three USB monitoring connections go to the Wysebox; separate AC outlets determine which machine each UPS protects.
