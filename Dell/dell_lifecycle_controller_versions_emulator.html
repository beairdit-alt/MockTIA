Student Tasks

Complete these tasks in the emulator and then grade the session.
1. Select PowerEdge R730 and identify BIOS, iDRAC, and Lifecycle Controller versions.
2. Open Lifecycle Log and identify the storage predictive-failure warning.
3. In Firmware Update, choose a repository, scan, validate, and complete an iDRAC/Lifecycle update.
4. In Hardware Configuration, create a simulated RAID 1 using two healthy drives.
5. Run diagnostics and identify the subsystem that reports a warning.
6. In OS Deployment, choose UEFI and Secure Boot Enabled, then complete the deployment simulation.
