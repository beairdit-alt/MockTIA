2.2.11 Lab: Choose and Install a Motherboard

Service Ticket

Upgrade an ATX workstation without replacing the existing Intel Core i5-12400 CPU or DDR4 RAM. Install a compatible motherboard and verify the machine boots.

Required hardware
CPU: Intel Core i5-12400
Socket: LGA1700
RAM: DDR4-3200
Case: ATX mid tower
Boot: existing NVMe drive

Tasks

Read each component label. LGA1700 alone is not sufficient: check DDR generation, form factor, and connectors too.
