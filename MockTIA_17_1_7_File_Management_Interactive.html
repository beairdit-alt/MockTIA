Command Reference

Use pwd to display your working directory, ls -la to list files (including hidden entries), mkdir to create directories, touch to create files, cp to copy, mv to move/rename, cat to read text, and rm to delete files. Deletion is simulated and cannot affect your computer.

Understanding the Terminal

A Linux terminal allows administrators to work with files on local or remote computers, even without a graphical desktop. Commands apply to your current working directory unless you specify another path.
